# 手动导入网民讨论（小红书 / Facebook 群组 / WhatsApp / 微信群等）

这些平台需要登录，且条款禁止自动抓取，所以由你自己复制内容到这里，管线每天会一起分析。

**方式 1：CSV**（推荐，见 `template.csv`）
列：`date,platform,channel,title,text,replies,likes,url`
platform 可填：Xiaohongshu / Facebook / WhatsApp / WeChat / Manual

**方式 2：TXT**
文件名以平台开头，如 `xiaohongshu_2026-10.txt`、`facebook_群组名.txt`；每段一个帖子/评论，段与段之间空一行。

请勿粘贴他人的电话、全名等个人资料；系统只保存 ≤120 字摘录且会去掉 @用户名。
也可以直接在看板「网民舆情」页的「手动导入」框粘贴，即时分析后下载 CSV 放进本文件夹。
